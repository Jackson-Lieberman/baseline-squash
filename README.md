# Baseline Squash

A 3D squash game that runs in the browser — one HTML file, no build step.

**Play:** open `index.html` in Chrome or Edge (or use the GitHub Pages link for this repo).

## Controls

| Key | Action |
| --- | --- |
| Arrows / WASD | Move — and aim where the ball lands as you hit |
| Space | Hit |
| ↑ + Space | Drop |
| ↓ + Space | Lob |
| Shift + Space | Boast |
| E | Appeal for a let |
| Esc | Pause |

Touch controls appear on phones and tablets.

## Features

- PAR scoring to 11, single game / best of 3 / best of 5
- Lets, strokes and no-lets judged on interference
- Ball physics with drag, wall and floor friction, a ball that warms up, and nicks
- Regulation court markings; four courts with different ball liveliness
- Computer opponent on three difficulty levels

## Presentation

- Sculpted, kitted athletes: faces, seven hair styles, shirts with names and numbers on the back, rackets with strung heads, shoes and wristbands
- Animation rig with planted feet, an athletic ready stance, racket preparation, lunges, follow-through, head tracking, and celebrations after each point
- Player cards with an overall rating and play style, plus a 3D player showcase on the match setup screen
- A "tale of the tape" match intro with a sweeping camera
- Broadcast scorebug with game-ball and match-ball tags, a camera that leans in on the point winner, and slow motion on winners
- Shot timing feedback (Perfect / Good / Stretched)
- Full-time match facts and player of the match
- Arrow-key menu navigation, a live ticker of the demo match on the home screen, and bloom lighting on desktop

Built with [three.js](https://threejs.org/) (loaded from a CDN).
